
# 🎯 Quiz Master - Quiz Website

A simple and interactive Quiz Website developed using HTML, CSS, and JavaScript.

## 🌐 Live Website

👉 [Click here to play the Quiz](https://albatross67013-ctrl.github.io/Quiz---website/)

## 📌 Project Description

Quiz Master is a web-based quiz application that allows users to answer multiple-choice questions and receive their score at the end of the quiz.

The website is designed with a simple and modern interface and includes a timer, score calculation, correct answer display, and restart option.

## ✨ Features

- 📝 15 Multiple-Choice Questions
- ⏱️ 15-Second Timer for Each Question
- ✅ Shows Correct Answer
- ❌ Shows Wrong Answer
- 📊 Calculates Score Percentage
- 🏆 Displays Final Result
- 🔄 Restart Quiz Option
- 📈 Question Progress Bar
- 📱 Responsive Design for Mobile Devices
- ✨ Simple Animations
